# E-Learn - Online Learning & Course Platform Landing Page

A modern, responsive e-learning and edutech landing page designed for showcasing online courses, platform metrics, student feedback, and educational resources[cite: 4]. Built using semantic HTML5, custom CSS3 styles, and Bootstrap Icons[cite: 4].

---

## 🚀 Live Demo

[View Live Project](https://azzmath-12.github.io/Project-8-E-Learn/)

---

## 📌 Features

- **Navigation & Brand Header**: Clean navigation bar with site branding, categorized link menus, and login/signup action buttons[cite: 4].
- **Hero & Search Banner**: Bold header image background with an integrated course search bar[cite: 4].
- **Platform Highlights & Stats**: Interactive feature callouts displaying course variety, expert tutors, and platform reach[cite: 4].
- **Course Showcase**: Responsive course cards complete with thumbnails, rating badges, duration/seat details, and pricing tags[cite: 4].
- **Video Introduction**: Interactive "Get Started" panel featuring embedded video media and play controls[cite: 4].
- **Student Reviews**: Testimonial showcase with student avatars, star ratings, and navigational controls[cite: 4].
- **Latest Blog & Articles**: Responsive grid layout featuring publication cards, tags, and read links[cite: 4].
- **Newsletter Subscription**: Centered email capture input for updates and course discounts[cite: 4].
- **Comprehensive Footer**: Categorized footer links with branding, contact details, and platform references[cite: 4].
- **Fully Responsive**: Media queries supporting seamless layouts across mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic web architecture and layout structure[cite: 4].
- **CSS3**: Custom variables, Flexbox, CSS Grid, and responsive media queries[cite: 4].
- **Bootstrap Icons**: Vector UI icons for ratings, features, and platform navigation[cite: 4].
